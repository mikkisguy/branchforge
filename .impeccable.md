# Design Context for BranchForge

## Users

**Visual novel authors and writers** who create branching narrative stories for Ren'Py. They work across multiple devices (desktop, tablet) and need a focused, distraction-free writing environment. Their context: drafting dialogue and narration, managing scene status (draft → review → final), and exporting to Ren'Py scripts.

## Brand Personality

**Inspiring • Gentle • Efficient**

The interface should feel like a quiet, welcoming creative space—not a harsh technical tool. Every interaction should feel smooth and considered. The polish builds confidence without being flashy.

- **Inspiring**: The UI should encourage creativity and flow
- **Gentle**: Approachable, calm, never overwhelming or aggressive
- **Efficient**: Respect the writer's time with keyboard shortcuts and thoughtful interactions
- **Polished**: Every detail considered, nothing feels half-baked

## Aesthetic Direction

**Dark, editor-focused interface with theme color accents.**

The existing design uses:

- **Dark mode by default** (better for long writing sessions)
- **4 theme palettes**: forest (green), periwinkle (blue-purple), dark-amethyst (purple), graphite (gray)
- **Kanit font** for UI (tracking-wide), custom font sizing for prose
- **Subtle dot pattern** background for visual interest without distraction
- **Thin custom scrollbars** (6px) that blend into the interface

**Avoid**: Generic corporate look, harsh contrasts, cold/utilitarian feel.

## Design Principles

1. **Respect the flow state**: Minimize friction, use smooth transitions, avoid jarring animations that break concentration

2. **Gentle feedback**: Use subtle hover states, breathing animations for save indicators, soft focus rings. Never aggressive or distracting

3. **Efficiency first**: Keyboard shortcuts, smart defaults, contextual actions. Power users should feel fast and capable

4. **Thoughtful details**: The little things matter—consistent spacing, optical alignment, proper typography hierarchy, polished empty states

5. **Theme cohesion**: All colors should work across the 4 theme palettes. Semantic colors (draft/review/final status) are theme-independent

## Quality Bar

**Flagship quality** — Sweat the details. This is a tool writers will spend hours in, so every interaction should feel exceptional:

- 60fps animations, only transform/opacity
- Smooth transitions (150-300ms) with ease-out-quart/expo easing
- All interactive states implemented (default, hover, focus, active, disabled, loading, error)
- No layout shift on load
- Accessible keyboard navigation
- Polished empty states and loading states
- Consistent spacing using design tokens
- Respect prefers-reduced-motion for accessibility

## Technical Notes

- **React 19 + TypeScript + Vite**
- **Tailwind CSS** with class-variance-authority for component variants
- **CSS custom properties** for theming (HSL format)
- **TanStack Query** for server state management
- **Lucide React** for icons
- **Mobile-responsive**: Works on tablet/phone form factors

## Theme Colors Reference

```css
/* Forest (green) */
--theme-primary: 154 52% 50%; /* HSL equivalent of #40bb82 */

/* Periwinkle (blue-purple) - default */
--theme-primary: 234 52% 51%; /* HSL equivalent of #3d4ac2 */

/* Dark Amethyst (purple) */
--theme-primary: 285 43% 51%; /* HSL equivalent of #9549b6 */

/* Graphite (gray) */
--theme-primary: 220 9% 62%; /* HSL equivalent of #9ca3af */
```

Status colors (theme-independent):

- Review: #f59e0b (amber)
- Draft: #64748b (slate)
- Final: uses theme color
