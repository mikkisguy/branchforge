# Goals & Themes

User settings control your account preferences across all projects.

## Themes and appearance

BranchForge ships with four color palettes:

- Forest
- Periwinkle (default)
- Dark Amethyst
- Graphite

Toggle **dark** or **light** appearance from the shell. Your choice persists
across sessions.

<!-- screenshot: settings-goals.png — User settings with daily goal and Forest theme, light mode -->

## Daily writing goal

Set a daily word-count goal to build a writing habit. Progress resets at the
hour you configure (default midnight in your timezone). Goals are optional —
leave the field empty to disable tracking.

## Profile

Upload an avatar and set a display username. These appear in the app shell and
project list.

## Post-v1 features

The following are **not** available in this beta release:

- **Beta reader management** — sharing projects with readers for feedback
- **Ren'Py snippets** — reusable script templates
- **Ren'Py definitions import wizard** — guided import for CHARACTER/TRANSFORM/IMAGE blocks

They may appear in a future release; see the GitHub issue tracker for status.
