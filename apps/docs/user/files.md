# File Management

Ren'Py projects are split across multiple `.rpy` files. BranchForge tracks each
file as a **project file** with its own label set and flow graph column in
FILE layout mode.

## Viewing files

In [Script Mode](./script-mode), the file tree lists every story file in the
project. Click a file to edit it; labels from that file appear in Write Mode's
navigator under the same path.

<!-- screenshot: file-management.png — Script Mode file row menu (rename/move/delete), dark theme, docs demo -->

## Creating files

Use **New File** in Script Mode or Write Mode. Enter a relative path such as
`labels/chapter_02.rpy`. The file is stored in BranchForge immediately and
included in [ZIP export](./import-export#zip-export) — it is not pushed to
GitLab until you push.

Reserved names (`branchforge_variables.rpy`, `branchforge_stats.rpy`,
`branchforge_definitions.rpy`) are generated by BranchForge and cannot be
created manually.

## Renaming and moving

Rename accepts a full relative path. BranchForge updates label associations and
waits for any pending autosave before applying the change.

## Deleting

Deletion shows impacted labels and incoming jumps. Large impacts require
confirming the file basename. GitLab-backed files can be restored before the
next push; ZIP-imported files are removed from the local project immediately.

## Sync behavior

- **ZIP import** — files keep their archive paths
- **GitLab pull** — paths mirror the repository
- **Export** — all active story files are written back to a Ren'Py-ready archive
