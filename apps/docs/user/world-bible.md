# World Bible

The world bible helps you track locations, items, concepts, and events that
appear across your story — independent of any single label.

## Element types

| Type         | Example                          |
| ------------ | -------------------------------- |
| **LOCATION** | "Café Lantern", "School rooftop" |
| **ITEM**     | "Silver locket", "Train ticket"  |
| **CONCEPT**  | "The prophecy", "Guild rules"    |
| **EVENT**    | "Festival night", "Power outage" |

Each entry has a name, optional description, and tags for filtering.

## When to use it

Use the world bible when you need a quick reference while writing — especially
for recurring places or lore that spans multiple routes. It does not replace
Ren'Py `define` statements or scene commands; those still live in
[Script Mode](./script-mode).

## Relationship to the flow graph

World bible entries are reference material. They do not create flow graph
nodes. Link ideas to scenes through your script and label notes as needed.
