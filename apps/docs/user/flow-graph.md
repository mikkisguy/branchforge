# Flow Graph

The Flow Graph provides a visual representation of your narrative flow, helping you understand branching paths at a glance.

## Layout Modes

BranchForge offers three layout modes for different visualization needs:

### Flow Mode (Default)

[screenshot of flow mode]

Hierarchical layout showing the narrative as a directed tree. Good for understanding the overall structure.

### Route Mode

[screenshot of route mode]

Columns organized by route. Good for comparing parallel paths side-by-side.

### File Mode

[screenshot of file mode]

Columns organized by source file. Good when your script is split across multiple RPY files.

## Dragging Nodes

[screenshot of node dragging]

Drag nodes to reorganize the graph. This does not change your script — it only changes the visual layout for exploration.

## Filtering

[screenshot of filter controls]

Filter the graph by:

- Route: Show only lines in specific routes
- Character: Show only dialogue from specific characters
- Status: Show only lines with specific status (draft, reviewed, etc.)

Filters combine, so you can drill down to exactly the lines you need to review.
