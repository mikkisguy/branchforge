# Organization

BranchForge organizes your work at three levels: account, project, and label.

## Account

Your account holds authentication, user settings (theme, daily writing goal,
avatar), and the project list. Each account can own multiple projects.

## Project

A project maps to one imported Ren'Py workspace. All characters, variables,
stats, routes, world bible entries, and `.rpy` files belong to a single
project. Projects are created by [importing](./projects) — never from an empty
template.

## Labels and files

Within a project, **labels** are the atomic story units (Ren'Py `label`
blocks). Labels live inside **project files** (`.rpy` files). The label
navigator groups labels by file; the [flow graph](./flow-graph) connects them
via jumps and menu choices.

## Modes of work

| Mode                         | Best for                          |
| ---------------------------- | --------------------------------- |
| [Write Mode](./writing)      | Prose and dialogue                |
| [Script Mode](./script-mode) | Conditions, menus, jumps, visuals |
| [Flow Graph](./flow-graph)   | Structure and branching overview  |

Use [routes and visibility](./routes) when your story has parallel paths, and
the [world bible](./world-bible) to track locations and concepts that span
multiple scenes.
