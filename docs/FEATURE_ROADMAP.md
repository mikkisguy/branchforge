### 10. Characters ✅ Fully Implemented

**Schema**: `characters` table

- `name`, `display_name`, `renpy_tag`, `color`, `dialogue_style`
- `route_affiliation`, `is_love_interest`, `pair_group_id`
- `avatar_url` for character profile images

**Implementation Status**:

- ✅ Backend routes: `characters.routes.ts` (full CRUD + avatar upload/delete + detect/import)
- ✅ Backend services: character service, character parser service, character linker service
- ✅ Frontend hooks: `useCharacters.ts` with avatar mutations
- ✅ Frontend UI: `CharacterDialog.tsx`, `CharacterImportWizard.tsx` with avatar upload, preview, and display
- ✅ File validation: 500KB limit, image type checking (PNG, JPEG, WebP, GIF)
- ✅ Static file serving: `@fastify/static` at `/public/avatars/`
- ✅ Cleanup: Avatar files deleted on character deletion

**Routes Implemented**:

```typescript
GET    /api/projects/:projectId/characters     // List characters
POST   /api/projects/:projectId/characters     // Create character
GET    /api/characters/:characterId             // Get single character
PUT    /api/characters/:characterId             // Update character
DELETE /api/characters/:characterId             // Delete character
POST   /api/characters/:characterId/avatar      // Upload avatar
DELETE /api/characters/:characterId/avatar      // Remove avatar
GET    /api/projects/:projectId/characters/detect // Detect from GitLab
POST   /api/projects/:projectId/characters/import // Import characters
```

**Avatar Specifications**:

- Format: WebP (converted from any input format)
- Max file size: 2MB
- Dimensions: 200px width (proportional height)
- Quality: 85
- Display: Circular with colored border matching `character.color`
- Fallback: Color circle displayed when no avatar

## Priority Recommendations

### High Priority (Core Features)

1. **Export Generation** (Exports table - 🟡 PARTIAL)
   - GitLab export works, but no direct zip file download
   - Impact: Can't easily download project files
   - Effort: Medium
   - Dependencies: RPY generator exists

2. **Meter Management** (Meters table)
   - Impact: Can't track relationship stats
   - Effort: Medium
   - Dependencies: None

3. **Label-Character Relationships** (Label Characters junction)
   - Impact: Can't associate characters with labels
   - Effort: Low
   - Dependencies: None

4. **Project Management** (Projects table - 🟡 PARTIAL)
   - Missing: Update/delete routes, beta reader management
   - Impact: Can't fully manage projects
   - Effort: Low

### Medium Priority (Enhanced Features)

5. **User Settings** (User Settings table - 🟡 PARTIAL)
   - Backend routes exist (GET/PUT), but missing UI for avatar upload, language switching, and username management
   - Theme is handled via ThemeContext rather than persisted to database
   - Impact: Limited profile customization
   - Effort: Low

6. **Visual System Configuration** (Visual Systems table)
   - Impact: Can't customize image naming
   - Effort: Medium
   - Dependencies: None

7. **Beta Reader Management** (Project Users junction)
   - Impact: Can't share projects with testers
   - Effort: Medium
   - Dependencies: None

### Lower Priority (Advanced Features)

8. **World Elements** (World Elements table)
   - Impact: No world bible tracking
   - Effort: Low
   - Dependencies: None

9. **Pair Groups** (Pair Groups table)
   - Impact: Can't track duo endings
   - Effort: Low
   - Dependencies: Characters, Meters

10. **AI Suggestions** (AI Suggestions table)
    - Impact: No AI-assisted writing
    - Effort: High
    - Dependencies: OpenRouter integration

11. **Import from External Sources** (Import Logs table)
    - Impact: Can't migrate from other tools (besides GitLab and zip)
    - Effort: High
    - Dependencies: None

## Notes

### Schema Terminology Change

The database uses "labels" (formerly "scenes") for Ren'Py label statements. This is distinct from Ren'Py's "scene" command for background changes.

### GitLab Integration

GitLab integration is fully implemented with:

- Encrypted PAT storage
- Repository linking
- Import/export with conflict detection
- Script mode editing with auto-sync to labels

### Soft Delete Pattern

Several tables use soft delete (`deleted_at` timestamp):

- `labels`
- `label_lines`

When implementing new features, follow this pattern for user-deletable content.

### Audit Trail

The `labels` table includes audit fields:

- `createdBy`, `updatedBy` (user references)
- `version` (integer)

Consider adding these to other tables for better change tracking.

### New Features Since Last Review

1. **Writing Goals** - Daily word count tracking (fully implemented)
2. **Zip Import** - Import Ren'Py projects from zip files (fully implemented)
3. **User Settings Routes** - Backend routes now exist (partially complete)
4. **Character Detection & Import** - Automatic character detection from GitLab files (fully implemented)

### Out of Scope

**Demo/Playback Mode**: The database schema exists, but this feature is considered out of scope for BranchForge. The focus is on authoring and managing visual novel content, not playback.
